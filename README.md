# Pokemon Java Projekt

Dieses Projekt ist ein einfaches Konsolen-Spiel in Java, das auf dem Pokemon-Konzept basiert.

## Beschreibung

In diesem Spiel übernimmt der Benutzer die Rolle eines Trainers. 
Am Anfang gibt der Spieler seinen Namen ein und wählt ein Starter-Pokemon aus (Glumanda, Schiggy oder Bisasam).

Das Spiel beinhaltet:
- Einen zufälligen Kampf gegen ein Wild-Pokemon
- Einen anschließenden Kampf gegen einen Rivalen (Gary)
- Ein einfaches Kampfsystem mit verschiedenen Attacken
- Ausgabe im Konsolenformat

## Features

- Auswahl eines Trainers und Starter-Pokemons
- Zufällige Begegnung mit Wild-Pokemon
- Rundenbasiertes Kampfsystem
- Unterschiedliche Attacken mit Schaden
- Gegner (Rivalen-Kampf)
- Nutzung von objektorientierter Programmierung (OOP)

## Technologien

- Java
- Eclipse (Entwicklungsumgebung)
- Objektorientierte Programmierung (Klassen wie Pokemon, Attacke, Trainer)

## Ziel des Projekts

Dieses Projekt wurde erstellt, um meine Kenntnisse in Java und objektorientierter Programmierung zu verbessern.  
Außerdem zeigt es meine Fähigkeit, Logik und Spielmechaniken selbst zu entwickeln.
